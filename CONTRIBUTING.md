# Contributing

Thanks for helping make Onism Play better. This repository holds release notes and issue tracking only. It doesn't contain the app's source code, so there's no code to send as a pull request.

## The most useful things you can do

- **Report a bug.** Open an issue with the bug report form. Include your Onism Play version, Mac model and macOS version, the game and its store, what happened and what you expected.
- **Suggest a feature.** Use the feature request form and say what problem it would solve for you.
- **Check first.** Search existing issues, and read the [Support guide](https://play.onism.ai/support/). Many launch problems clear up after a quick backend switch or permission check.

## Before you post

- Don't include account details, passwords or logs that contain them.
- One problem per issue makes it easier to follow.
- Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Pull requests

Pull requests with documentation fixes, such as typos in the README or changelog, are welcome. Changes to the app itself can't be accepted here.

For security problems, see [SECURITY.md](SECURITY.md). To reach us privately, email support@onism.ai.
