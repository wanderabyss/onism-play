# Onism Play

Run Windows games on your Mac. Onism Play is a native Apple Silicon app that installs and plays your Steam, Epic Games, GOG, Ubisoft Connect and EA app libraries, and manages Wine engines, graphics backends and per-game tuning in one place.

- Website and download: https://play.onism.ai
- Latest release: see [Releases](https://github.com/wanderabyss/onism-play/releases) and the [Download page](https://play.onism.ai/download/)
- What changed: [CHANGELOG.md](CHANGELOG.md)
- Contact: play@onism.ai

## Requirements

- Mac with Apple Silicon (M1 or later)
- macOS 26 or later

## About this repository

This repository holds release notes, tags and issue tracking for Onism Play. It does not contain the app's source code. Check the SHA-256 on the download page before opening a disk image.

## Reporting problems

Open an issue and include your macOS version, the game, the store it came from, and what you expected to happen. Please don't post account details or logs that contain them.

## Open-source components

Onism Play bundles open-source software, including Legendary (GPLv3). The Legendary source that matches the shipped version is available from the download page.

Onism Play is an independent project. Game names and store names belong to their owners.
